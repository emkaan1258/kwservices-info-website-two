# Vidalesservice site (React + Tailwind + Vite)
    npm install && npm run dev      # http://localhost:5173
    npm run build                   # production build in dist/
- Business details: `src/config.js` (phone/email/address are blank until you fill them in; links appear automatically)
- Copy: `src/data/content.js`; legal text: `src/data/policies.js`; theme tokens: `tailwind.config.js`
